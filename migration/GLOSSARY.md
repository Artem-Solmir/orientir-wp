# GLOSSARY

| Термин | Значение |
|---|---|
| ETL | Идемпотентный перенос данных из MySQL WordPress в PostgreSQL; повторный запуск не создаёт дубликатов |
| Дельта-ETL | Догрузка только изменений после последнего прогона, перед переключением |
| Заморозка | Остановка публикаций и регистраций на WordPress на время финальной дельты и переключения DNS |
| Снимок | Дамп базы на конкретную дату (локальный: 2026-10-15) |
| owner | Роль владельца сайта: единственный, кто публикует новости |
| user | Зарегистрированный пользователь с личным кабинетом, без права публикации |
| Agent API | API для AI-агента, который заменяет WP-админку; доступ по сервисному токену или сессии owner |
| sessionVersion | Счётчик в профиле пользователя для отзыва JWT-сессий |
| ISR / revalidate | Перегенерация статических страниц Next.js по требованию после изменения контента |
| pending | Статус пользователя WP без подтверждения; кандидаты на исключение из переноса |
| Golden URL tests | Тесты, проверяющие, что старые URL отдают тот же контент или 301 |
| Легаси-архив | Сохранённая копия WordPress после переключения (только для чтения) |
