# Agent API: операции для ИИ-агента

Все запросы: заголовок `Authorization: Bearer <AGENT_API_TOKEN>`, тело JSON (UTF-8). Токен хранится только в локальном env агента, ротация: заменить значение в `.env` на сервере и у агента.
Ответы всегда с `Cache-Control: no-store`. Лимиты: 600 успешных запросов в час, 10 неверных токенов за 15 минут с одного IP (дальше 429).
Коды: 401 нет/неверный токен, 404 не найдено, 409 slug занят, 413 тело больше 1 МБ, 422 ошибка валидации (в `issues` пути и сообщения), 429 лимит.

| Операция | Запрос |
|---|---|
| Список записей | `GET /api/agent/posts?limit=20&offset=0&q=текст&status=published\|archived` |
| Одна запись (с body) | `GET /api/agent/posts/{slug}` |
| Создать и сразу опубликовать | `POST /api/agent/posts` |
| Изменить | `PATCH /api/agent/posts/{slug}` (любое подмножество полей, в т.ч. `status`) |
| Убрать с сайта | `DELETE /api/agent/posts/{slug}` (мягко: статус `archived`) |
| Изменить страницу | `PATCH /api/agent/pages/{slug}` (`title`, `body`) |
| Заявки с формы | `GET /api/agent/submissions?status=new` |
| Отметить заявку | `PATCH /api/agent/submissions/{id}` `{ "status": "processed" \| "rejected" }` |

Поля записи: `title` (3-200), `body` (HTML, прогоняется через общий sanitizer, скрипты и опасные атрибуты вырезаются), `slug` (необязательно, иначе транслитерация заголовка; зарезервированные и занятые отклоняются), `excerpt`, `categories` (slug существующих рубрик), `tags` (имена, новые создаются), `publishedAt`, `expiresAt`, `coverPath` (путь существующего медиафайла), `authorName`, `seoTitle`, `seoDescription`.

Каждая запись пишет строку в `AuditLog` (без текста body). После записи кэш сайта сбрасывается, редеплой не нужен.

Не реализовано: загрузка медиа (хранилище выбирается до Фазы 6; фото берём из публичных папок Яндекс Диска), правка секций главной.
